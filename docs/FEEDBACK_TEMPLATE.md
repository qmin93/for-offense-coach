## 분석 가이드

### 점수 해석

| 평균 점수 | 상태 | 액션 |
|----------|------|------|
| 4.5+ | 매우 좋음 | P2 진행 |
| 4.0-4.4 | 좋음 | P2 진행 가능 |
| 3.5-3.9 | 보통 | 상위 문제 1-2개 패치 후 진행 |
| 3.0-3.4 | 미흡 | P1.2 폴리싱 필요 |
| <3.0 | 심각 | 핵심 기능 재검토 |

### 문항별 목표

- **Q1 추천이유**: 4.0 이상
  - 3.5 미만 → 추천 로직/이유 텍스트 개선

- **Q2 자동생성**: 3.5 이상
  - 3.0 미만 → 템플릿 품질 전면 재검토

- **Q3 PDF품질**: 4.0 이상
  - 3.5 미만 → 렌더링/레이아웃 수정
